# Power BI Reports

## 1. Présentation

Ce dossier contient les fichiers de restitution du projet Retail Intelligence développés avec Microsoft Power BI.

## 2. Rapport principal

Le rapport principal du projet est :

`Retail_Intelligence.pbix`

Il comprend six pages :

1. Executive Overview
2. Sales Performance
3. Product Analysis
4. Customer Analysis
5. Geographic Analysis
6. Cancellations & Negative Movements

## 3. Formats de fichiers

Les formats pouvant être conservés dans ce dossier sont :

- `.pbix` : fichier Power BI principal, contenant le rapport et ses éléments de conception.
- `.pdf` : export statique du rapport, uniquement si une version PDF est produite.

## 4. Organisation

Les fichiers doivent être nommés de manière explicite afin de faciliter leur identification et leur maintenance.

Le fichier Power BI principal doit rester facilement identifiable.

## 5. Remarque

Le fichier `.pbix` constitue la version principale et modifiable du rapport. Une éventuelle version PDF est une copie destinée à la consultation et ne remplace pas le fichier Power BI.
